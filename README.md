# Chest Tumor Detection Diffusion Model

Hey there! This repo is all about a cool diffusion-based model for chest tumor detection. It's built with a U-Net architecture and some multi-head attention, scoring a solid 95.63% accuracy with an MSE loss of 0.027 – way better than those old-school CNNs.
